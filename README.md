# MovieVerse XAMPP Project

A multi-page movie recommendation website built with **PHP + MySQL + HTML/CSS/JS** for running on **XAMPP**.

## Features
- Automatic database and table creation in `db.php`
- User register/login
- Admin login (`adi@gmail.com` / `123`)
- Admin dashboard to add movies and view reports
- Category filters (Horror, Thriller, Romantic, Sci-Fi, Action, Comedy, Drama)
- Watchlist support
- 3D/animated UI in black/blue/purple palette
- Teaser modal and hover previews
- 10+ pages and report pages

## Setup
1. Place project in `htdocs/movieverse`.
2. Start Apache and MySQL in XAMPP.
3. Open: `http://localhost/movieverse/index.php`
4. The app creates DB/tables automatically.
